Ejercicio colores CSS. • Para obtener las equivalencias entre códigos de color o los nombres de éstos como colores seguros, busca páginas en Internet relativas al uso del color en HTML y CSS, como, por ejemplo: o https://htmlcolorcodes.com/es/ • Abre la página Web Colores.html • Crea las reglas CSS que permitan aplicar a cada división un color según las siguientes consideraciones: o En el primer grupo de divisiones con el título Color Verde Claro aplica el mismo color verde claro a cada división usando, en este orden, el nombre del color, su valor RGB, su valor en RGB con un 70% de opacidad y su valor en hexadecimal. o En el segundo grupo de divisiones con el título Color Rojo aplica el mismo color rojo a cada división usando, en este orden, el nombre del color, su valor RGB, su valor en RGB con un 70% de opacidad y su valor en hexadecimal. o En el tercer grupo de divisiones con el título Escala Transparencia Azul, aplica el mismo color azul a cada división usando el mismo modelo de color, pero con una opacidad decreciente del 100% a 10 %, con saltos de 10 en 10 por ciento. • Nota. o Tanto las reglas CSS incluidas en el ejercicio como las que hay añadir, guárdalas en un archivo aparte con el nombre colores.css o Crea la carpeta css y guarda el ella el archivo colores.css.

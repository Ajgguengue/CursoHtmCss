Crear una lista de definiciones para los siguientes terminos. Puedes buscar la informacion en Google

HTTP:

Es el protocolo o "lenguaje" que permite la transferencia de información y páginas web entre un navegador y un servidor Wikipedia.

HTML:

El lenguaje de marcado estándar utilizado para crear y estructurar el contenido (texto, imágenes, enlaces) de las páginas web MDN Web Docs.

URL:

Es la dirección específica y única que se utiliza para localizar un recurso (como una página o una foto) en la red HubSpot.

TCP/IP:

Es el conjunto de reglas básicas que permiten que las computadoras se comuniquen entre sí y formen la red de redes Avast.

Internet:

Una red global descentralizada de computadoras interconectadas que utilizan el protocolo TCP/IP para compartir información GCFGlobal.

W3C:

El consorcio internacional que genera recomendaciones y estándares (como el HTML) para asegurar el crecimiento de la web a largo plazo World Wide Web Consortium.

Mozilla Foundation:

Una organización sin fines de lucro que promueve la apertura, innovación y oportunidad en la web, conocida principalmente por desarrollar el navegador Firefox Mozilla.org.
